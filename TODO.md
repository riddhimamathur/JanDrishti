# JanDrishti implementation checklist

- [x] **Responsive civic interface and global navigation.** Build a responsive, accessible civic interface using the specified light palette (#F8FAFC background, #FFFFFF cards, #1E3A8A primary, #D97706 accent, #1E293B text, #64748B metadata) and Inter/system-ui typography. Use HTML5, Tailwind CSS, and Vanilla JavaScript. Include a fixed top navigation with JanDrishti logo/name, global project search, filter panel with Department, State, District (including Jaipur, Chomu, Bikaner and other local districts), and Project Start Date; language selector for English, Hindi, Gujarati, Marathi, Bengali, Telugu, Kannada; history, bookmarked projects, notifications, and right-side Login/Sign Up/Sign In/Logout and profile states.
- [x] **Maps and settings sidebar.** Include a Maps button that toggles an interactive mock India map, supports state selection and state-level views, and shows a bottom-right summary of Ongoing Projects, New Projects, and Recently Ended Projects. Include bottom-left Settings for theme adjustment, feedback submission, and bug reporting, each with a clear mock success state.
- [x] **Activity feed and geolocation fallback.** The default feed shows recent project happenings, news, and updates based on browser geolocation when permitted; when unauthenticated, location is disabled, or permission is denied, show latest ongoing project updates as a fallback.
- [x] **Project cards, data and bookmark behavior.** Use realistic mock project and update content. Cards are horizontal, with a thumbnail on the left, title, department name, truncated description, location at top-right, and a divider row for estimated completion, project update date, and start date. Include working project bookmarking.
- [x] **Client-side navigation states and mock data.** Provide mock authentication states and interactions for Login, Sign Up, Sign In, Logout, and profile display; history of checked projects; starred/bookmarked projects; notification items; and an accessible, practical language selector with seven named languages. Do not require backend services or live government integrations.
- [x] **Organized handoff and GitHub instructions.** Deliver clean, organized frontend source files and clear step-by-step terminal commands for `git init`, staging all files, committing, setting the branch, adding a GitHub remote, and pushing.
