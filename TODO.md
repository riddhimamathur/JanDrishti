# JanDrishti implementation checklist

- [x] **Responsive civic interface and global navigation.** Use a responsive, accessible light civic theme with background #F8FAFC, white cards, deep blue #1E3A8A, amber #D97706, dark slate #1E293B, muted metadata #64748B, and Inter/system-ui typography. Keep the fixed top navigation with JanDrishti logo/name, global project search, a filter panel for Department, State, District (including Jaipur, Chomu, Bikaner, etc.), and Project Start Date; an eight-language selector for English, Hindi, Gujarati, Marathi, Odia, Bengali, Telugu, and Kannada; History and Star/Pinned views; notification bell; and Profile/Auth controls for Login, Sign Up, Sign In, and Logout. Localize visible navigation, feed, card metadata, maps, settings, filters, notifications, and dialog UI when the user changes language.
- [x] **Maps and settings sidebar.** Include a Maps button that toggles the interactive mock India map; clicking a state displays that state's map and a bottom-right summary card for Ongoing, New, and Recently Ended project counts. Include bottom-left Settings for theme adjustment, feedback, and bug reporting.
- [x] **Activity feed and location fallback.** The default view is a feed of recent project updates based on geolocation or randomized ongoing updates when unauthenticated/location is unavailable. Keep that randomized ordering stable through reloads in the same browser tab/session.
- [x] **Project cards and mock project data.** Use horizontal cards with a left thumbnail, title, department, truncated description, top-right location tag (e.g. “Jaipur, Rajasthan”), and bottom metadata divider row for “Estimated completion”, “Project Updation”, and “Started on”.
- [x] **Persistent Friendly Professor assistant.** Keep the global assistant available across all screens/views and forward/backward view navigation; match assistant UI, explanatory replies, and sample-record descriptions/latest updates to the selected language while preserving project proper names and numeric facts; allow detailed project questions; and, when opened, let the user choose between a Full-Screen Bot and a Minimized / Small Floating Widget view.
- [x] **Accessible dialogs and keyboard focus.** Give application and full-screen assistant dialogs accessible names, trap Tab focus while modal, close with Escape, and restore focus to the invoking control.
- [x] **GitHub handoff instructions.** Provide exact commands to initialize Git, stage all files, commit, set branch `main`, add remote `https://github.com/riddhimamathur/JanDrishti.git`, and force push with `git push -u origin main --force`. Include the root-level compiled `styles.css` so the pushed repository can render when served as a static site from its root.
